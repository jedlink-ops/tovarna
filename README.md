# Můj rozvaděč – Jedlink Elektro

Nástroj pro návrh rozvaděčů: osazení přístrojů, kontrola, kusovník, dokumentace a typový štítek.

Běží na GitHub Pages: https://jedlink-ops.github.io/tovarna/

Celá stránka je v jednom souboru `index.html`. Data (zakázky, vlastní šablony) se ukládají jen v prohlížeči zařízení; přenášejí se přes „Uložit / Otevřít zakázku“.

Původní hra Zelené Údolí je zachovaná ve větvi `hra-zaloha`.
